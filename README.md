## About
This repository is made for practicing the basic features of GitHub and Markdown.  
It helps you understand how to create a README file, format content properly, and organize a project in a simple and readable way.

## Features
- Basic Markdown headings and text formatting.
- Lists, links, and code blocks.
- Simple project structure for learning.
- Practice with GitHub repositories and commits.
- Easy-to-read README layout.

## What I Learned
- How to create a `README.md` file.
- How to use headings, paragraphs, and bullet points.
- How to write code in markdown using backticks.
- How to add links and organize sections.
- How GitHub displays Markdown files automatically.
